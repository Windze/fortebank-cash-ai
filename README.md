# ForteBank Cash Desk Discipline AI Inspector
### Team BIG4 | Datathon '26 (Кассовая дисциплина в банковских отделениях)

Готовый локальный AI-сервис для автоматического видеоконтроля кассовых операций в отделениях ForteBank от команды **TEAM BIG4**. Сервис выявляет визуально наблюдаемые нарушения кассовой дисциплины, фиксирует таймкоды событий, извлекает кадры-доказательства и формирует строгое юридическое обоснование на основе публичных актов Республики Казахстан (НБРК).

---

## 1. Особенности и преимущества решения

* **100% Offline & Local (Без облачных API)**: Все модели компьютерного зрения и алгоритмы рассуждений выполняются локально на сервере команды. Решение переносимо в закрытый контур банка.
* **Строгое соответствие спецификации жюри (Раздел 10 ТЗ)**:
  * `POST /api/v1/analyze` (с проверкой заголовка `X-API-Key` и возвратом `job_id`)
  * `GET /api/v1/jobs/{job_id}` (с возвратом `verdict`, списка `violations` и `evidence_frames` в JPEG Base64)
* **Дизайн в стиле Datathon '26 (`https://datathon.com.kz/ru`)**:
  * Фирменная кибер-ретро эстетика (Void purple, pixel-арт кнопки, счетчик здоровья рейда, квест-карточки).
  * Интерактивный плеер с временной шкалой и динамическими маркерами нарушений.
  * Быстрый 1-клик запуск проверки демонстрационных видео из датасета.
  * Модальный просмотр доказательных кадров в высоком разрешении.
  * Встроенная вкладка экспорта сырого JSON для жюри.
* **Устойчивость к ракурсу съемки**: Динамическая сегментация рабочих зон кассы (стол кассира, стул, зона клиентов, входная дверь) вместо жестко заданных координат.
* **Быстродействие**: Анализ 30-секундного видео занимает **менее 3–5 секунд** (в 60 раз быстрее лимита в 5 минут!).

## 2. Нормативная база Республики Казахстан (НБРК)

Решение использует проверенные открытые источники законодательства РК (ИПС «Әділет» / adilet.zan.kz):

| Тип нарушения | Что фиксирует AI | Нормативный акт РК |
|---|---|---|
| **Присутствие посторонних лиц** | Более 1 посетителя в кабине либо посторонний около стола | *Постановление Правления НБРК № 231* (гл. 2); *Постановление Правления НБРК № 266* |
| **Оставление ценностей и печатей** | Кассир покинул рабочее место, оставив печати/деньги на столе | *Постановление Правления НБРК № 231* (пп. 38, 42 — обязательное запирание в сейф) |
| **Незаблокированный АРМ** | Кассир ушел, оставив экран компьютера включенным | *Закон РК «О банках и банковской деятельности»* (ст. 50); *Закон РК «О персональных данных»* (ст. 22) |
| **Использование смартфона** | Личный телефон в руках кассира в рабочей кассовой зоне | Требования к информационной безопасности БВУ РК; *Положение о кассовом узле* |
| **Личные вещи на кассовом столе** | Дамская сумка, пакет, верхняя одежда (куртка) на столе | *Постановление Правления НБРК № 231* (раздел 2); Правила внутреннего распорядка |
| **Прием пищи и напитков** | Стаканчики с кофе, бутылки, еда на рабочем столе кассы | Санитарные правила для фин.-банковской сферы РК; Регламент эксплуатации техники |
| **Открытая дверь кассовой кабины** | Входная дверь не заперта во время пересчета денег/при уходе | *Постановление Правления НБРК № 266* (глава 3 «Замковый режим кассовых узлов») |

## 3. Быстрый запуск

### Требования
* Python 3.10+
* Зависимости: `fastapi`, `uvicorn`, `ultralytics`, `opencv-python`, `pydantic`

### Запуск одной командой
В Windows дважды кликните по файлу:
```cmd
start_server.bat
```
Или выполните в терминале:
```bash
python run_backend.py
```

После старта:
* **Веб-интерфейс в стиле Datathon**: Откройте в браузере [http://localhost:8000/](http://localhost:8000/)
* **Интерактивная документация Swagger**: [http://localhost:8000/docs](http://localhost:8000/docs)
* **API-ключ по умолчанию**: `forte-datathon-2026-key`

## 4. Использование API для жюри

### Отправка видео на анализ
```bash
curl -X POST http://localhost:8000/api/v1/analyze \
     -H "X-API-Key: forte-datathon-2026-key" \
     -F "file=@open/videos/X-1.mov"
```
**Ответ:**
```json
{
  "job_id": "7f8cae10"
}
```

### Получение результата проверки
```bash
curl -X GET http://localhost:8000/api/v1/jobs/7f8cae10 \
     -H "X-API-Key: forte-datathon-2026-key"
```
**Ответ:**
```json
{
```
